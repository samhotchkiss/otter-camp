# Task Workflow Lanes

Move task/spec files through these lanes in order:

1. `01-ready`
2. `02-in-progress`
3. `03-needs-review`
4. `04-in-review`
5. `05-completed`

Conventions:
- Keep one task per file.
- Prefix filenames with sortable IDs (for example: `task-001-auth-bootstrap.md`).
- Move (do not copy) files between lanes.
